# UNIS : les 27 images qui manquent encore, prompts prêts à coller

Chaque prompt est **complet** : il suffit de copier le bloc gris dans l'IA d'image (Midjourney, DALL·E, Firefly, Ideogram, Flux, Gemini…). Rien à remplacer.

- Les prompts sont en anglais : les IA d'image les comprennent mieux.
- La fin `--no …` est la liste de ce qu'il ne faut pas voir sur l'image. Dans les outils sans `--no`, colle-la dans le champ « negative prompt », ou écris « Avoid: » devant.
- `--ar 1:1` donne le format de l'image (carré). Si l'outil ne le comprend pas, choisis le format à la main.
- **Avant de m'envoyer une image, vérifie** : Bo **sans sourcils**, aucun texte, aucun logo, aucun enfant, et les couleurs du motif proches de la description.
- Envoie-les-moi ici : je les vérifie, je les convertis en WebP et je les mets en ligne.

**Image de référence de Bo : [assets/reference/bo-reference.jpg](../assets/reference/bo-reference.jpg)** (Bo de Noël, debout de face, fond blanc, sans sourcils). Joins-la à chaque prompt où Bo apparaît (n° 16 à 22 et 27), comme « image de référence » ou « character reference » (`--cref` dans Midjourney). Ajoute au début du prompt : `Use the attached teddy bear as the exact character reference: same face, fur, eyes and proportions. Change only the bow color, the thong and the accessories.`
